# Aggregate Results

This directory contains aggregate reproducibility artefacts supporting the reported benchmark, including model-level latency, allocated VRAM, precision, recall, micro-F1, confidence intervals, and per-label summary statistics.

The aggregate values reported in the submitted paper are available in:

- [Table 1: candidate VLM baseline comparison](tables/table1_candidate_vlm_baselines.csv)
- [Table 2: Qwen quantization comparison](tables/table2_qwen_quantization.csv)
- [Table 3: Qwen-to-CheXAgent distillation comparison](tables/table3_qwen_chexagent_distillation.csv)

The institutional dataset and all patient-level outputs are not distributed. In particular, this repository does not include generated reports, image or DICOM files, case identifiers, filenames, split manifests, or per-sample metrics. This restriction protects patient privacy and follows the applicable institutional data-governance requirements.

The reported tables and figures can be regenerated by applying the scripts in `src/` to an appropriately approved local dataset under the configuration described in `docs/reproducibility.md`.
