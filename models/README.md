# Model Availability

The teacher runtime used in the experimental environment is `unsloth/Qwen3.5-9B`, with architecture `Qwen3_5ForConditionalGeneration`. The model identifier is recorded in `configs/paper_experiment.example.yaml`.

The project does not redistribute Qwen, CheXAgent, X-Raydar, or other third-party model files. Users must obtain each upstream model from its authorised source and comply with its licence and access conditions.

Trained LoRA adapter weights are not included in this repository. Any future distribution of adapters is subject to author-team approval, upstream licences, and institutional governance.
