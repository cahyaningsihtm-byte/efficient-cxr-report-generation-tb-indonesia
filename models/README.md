# Model Availability

The teacher runtime used in the verified experimental environment is `unsloth/Qwen3.5-9B`, with architecture `Qwen3_5ForConditionalGeneration`. The camera-ready release will record the corresponding immutable revision and the official model citation in the experiment manifest.

The project does not redistribute Qwen, CheXAgent, X-Raydar, or other third-party model files. Users must obtain each upstream model from its authorised source and comply with its licence and access conditions.

Trained LoRA adapter weights are not included in this repository. Their availability, if approved by the author team and consistent with upstream licences and institutional governance, will be documented in the final archival release.
